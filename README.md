# Темка

Мобильный симулятор бизнеса: от кофейни в деревне Копеечкино до монополии в мегаполисе Капитальске.
Вертикальный экран, управление одним пальцем, воксельная 3D-графика на three.js, работает как PWA прямо из браузера.

## Запуск на ПК

Нужен Node.js 20 или новее (https://nodejs.org, версия LTS).

```bash
npm install     # один раз
npm run dev     # запуск, игра откроется по адресу из консоли
```

В консоли будут две строки: `Local` для ПК и `Network` для телефона.

## Быстрый тест в одном HTML-файле

```bash
npm run html
```

Получится `dist-single/game.html`: вся игра в одном файле, открывается двойным кликом в Chrome, Edge или Safari, без сервера и сертификатов. Офлайн-режима и установки как приложения в этом варианте нет.

## Телефон по Wi‑Fi

Телефон и ПК должны быть в одной Wi‑Fi сети. Открой на телефоне адрес из строки `Network`, например `https://192.168.1.5:5173`.

**Быстрый способ (без настройки).** Браузер покажет предупреждение о сертификате: нажми «Дополнительно» → «Перейти на сайт». Игра откроется, но установить её как приложение и играть офлайн так не получится.

**Полный способ (PWA, установка на экран, офлайн).** Нужен доверенный локальный сертификат:

1. Установи mkcert на ПК. Windows: `winget install FiloSottile.mkcert` (или `choco install mkcert`). macOS: `brew install mkcert`.
2. В папке проекта выполни `npm run certs`. Команда создаст `certs/` и покажет, где лежит `rootCA.pem`.
3. Перенеси `rootCA.pem` на телефон и установи его:
   - **Android:** Настройки → Безопасность → Шифрование и учётные данные → Установить сертификат → Сертификат ЦС.
   - **iPhone:** открой файл, установи профиль в «Настройки → Профиль загружен», затем включи доверие в «Настройки → Основные → Об этом устройстве → Доверие сертификатам».
4. Перезапусти `npm run dev`. Теперь телефон открывает игру без предупреждений.
5. Для проверки офлайн-режима и установки: `npm run phone` (собирает игру и раздаёт готовую сборку). В браузере телефона: «Добавить на главный экран».

Если телефон не открывает адрес, разреши Node.js доступ к частным сетям в брандмауэре Windows (окно появляется при первом запуске).

Если IP компьютера в сети поменялся, запусти `npm run certs` ещё раз.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | разработка с автообновлением, доступ с телефона |
| `npm run html` | вся игра в одном `dist-single/game.html` для теста двойным кликом |
| `npm run phone` | сборка и раздача готовой версии (PWA, офлайн) |
| `npm run build` | проверка типов и сборка в `dist/` |
| `npm test` | автотесты |
| `npm run certs` | доверенный сертификат для телефона через mkcert |

## Устройство проекта

```
src/
  main.ts           точка входа: рендерер, камера, перерисовка только при изменениях
  sim/              ядро симуляции на чистом TypeScript (без three.js и DOM)
    data/*.json     ниши, форматы, деревни и участки, отделы, налоги, кредиты, карточки
    market.ts       формулы игрового дня (поток, очередь, качество, довольство, прибыль)
    actions.ts      действия игрока: открыть, нанять, зал, прокачки, отделы, выкуп, формат, УСН, кредит
    tick.ts         конец дня, сезона и года: налоги, Хваткин, овердрафт, захват деревень
    cards.ts        движок карточек решений
    manager.ts      управляющий точки
    strategies.ts   стратегии из модели баланса (для тестов и автопилота)
  save/             сохранение в IndexedDB и код прогресса
  scene/            воксельная деревня: layout.ts (участки), buildings.ts (здания точек),
                    lots.ts (перестройка по ходу игры), people.ts (гости), world.ts (время суток)
  ui/               play.ts — экран поверх сцены; balance.ts — шторки и подробный текстовый режим
  i18n/             все тексты игры (сейчас русский)
scripts/model-parity.py  сверка ядра с моделью баланса
public/icons/       иконки PWA
```

## Экран игры (этап 2)

Деревня строится по состоянию игры: на каждом участке здание точки (игрока — бирюзовое, Хваткина — красное) или пустой участок. День идёт сам (2 минуты при ×1, с 7:00 до 23:00), потом показываются итоги дня, утром — карточки решений. Справа: пауза, ×3, ⏭ к итогам, 🏢 отделы, 📊 подробный текстовый режим. Тап по дому или подписи над ним открывает шторку участка; у своей точки снимается крыша. Адрес с `#pause` запускает игру на паузе (для проверок). Прогресс сохраняется на устройстве сам, «Код прогресса» в подробном режиме переносит игру на другое устройство.

## Рост и ниши (этап 3)

- Офлайн-прогресс: ритм «10–15 минут игры (5–7 дней), потом 3–4 часа офлайна». Пока игры нет на экране, день идёт за каждые полчаса, но не больше 7 дней (неделя за 3,5 часа); карточки решаются осторожно или управляющим. При возвращении — сводка «Пока тебя не было».
- Захват деревни отмечается в итогах дня, камера летит к открывшейся деревне.
- 60 карточек решений (`src/sim/data/cards.json`), 12 из них сезонные (`seasons`: 0 весна, 1 лето, 2 осень, 3 зима). У каждой ровно один осторожный вариант; осторожная игра стоит 10–15% темпа (`tempo.test.ts`).
- Автопроверка в `src/ui/tutorial.test.ts`: игрок, который делает только то, что советует подсказка, доходит до третьей точки без отказов.

## Сверка с моделью баланса

Ядро повторяет `planning/balance/sim.py` один в один: тест `src/sim/parity.test.ts` прогоняет все стратегии модели и сверяет захват деревень и кассу до 1 баблоса. Если модель поменялась:

```bash
python3 scripts/model-parity.py путь/к/planning/balance/sim.py   # обновит src/sim/fixtures/model-parity.json
npm test
```

Если тест падает, значит формулы в `src/sim` нужно догнать до модели.

# Темка — заметки для работы над кодом

- Общение с автором (FAJI) и все тексты в игре — на русском. Тексты только через `src/i18n` (позже возможен испанский).
- Игра оригинальная: свои названия, модели и тексты, без копирования чужих игр.
- Стек: Vite + TypeScript (strict) + three.js, UI — HTML/CSS поверх canvas, PWA через vite-plugin-pwa, сохранения в IndexedDB.
- Симуляция — чистый TS без three.js и DOM, детерминированная, покрыта тестами (vitest). Баланс и карточки — JSON.
- Графика: воксели 0.25 м, InstancedMesh, сцена перерисовывается только при изменениях. Цель — 60 кадров на телефоне автора.
- Перед пушем: `npm run typecheck && npm test && npm run build`.
- Работа идёт по этапам плана (ссылки в README), каждый этап — отдельная ветка и pull request.
